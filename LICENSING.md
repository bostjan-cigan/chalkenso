# Licensing, in plain words

This repository is the **local edition** of Chalkenso: the same web app that runs the cloud
version, for you to host yourself. It is **source-available** under the
[Business Source License 1.1](LICENSE) (`BUSL-1.1`). It is not "open source" yet: each version
becomes open source four years after it is published.

The license text and its parameters in [LICENSE](LICENSE) are what count. This page only explains
them.

## Free for everyone

- Reading, copying, changing and sharing the code.
- Any use that isn't production: trying it out, development, testing.

## Free for personal use

Running it for real ("production use") is free for an individual using it for their own personal
purposes, with no commercial purpose and not on behalf of any organisation: personal study,
research, hobby projects, or a course you teach for free in your own time.

## Needs a license

Production use by or for anyone else, including:

- **schools, universities and other educational institutions**, public or private;
- training providers, bootcamps and academies;
- companies running internal training;
- independent trainers who sell courses or teach for a fee with it;
- teachers and instructors using it for their work;
- offering it as a hosted service to others.

For these, use the **cloud version**, or ask for a **license for your organisation** to host it
yourself. Both come with the same help: setup, processes and course reviews.

## Becomes open source

Each version of the code becomes available under the **Apache License 2.0** four years after it
is published.

Ask at [info@chalkenso.com](mailto:info@chalkenso.com), or use the hosted version at
[chalkenso.com](https://chalkenso.com).
